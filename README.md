# [Portfolio](https://imnel.github.io)

My personal site and blog built with SvelteKit (static adapter), Svelte 5 and Tailwind CSS v4. 

The theme is [Flatwhite](https://github.com/biletskyy/flatwhite-syntax/) by [biletskyy](https://github.com/biletskyy).

## Development

Since the code is static, a simple `pnpm i` and `pnpm dev` should suffice.
